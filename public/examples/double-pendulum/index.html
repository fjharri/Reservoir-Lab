WHAT IS BEING TESTED

Adapt before the next reading.

Fixed dynamics

The reservoir contains sparse, seeded recurrent connections that never train. Each sensor observation produces a nonlinear state representation with memory of the recent motion.

Online learning

Recursive least squares updates only the six-output linear readout. The update uses the newly arrived observation as the target for a forecast made 250 or 500 milliseconds earlier.

The deadline

At 30 Hz the model has 33 milliseconds to process an observation; at 60 Hz it has 17 milliseconds. Responses arriving later count as missed deadlines.

Interpretation

This demonstrates a workload an ESN can handle efficiently on this device. It does not by itself prove that every conventionally trained recurrent network would fail.
